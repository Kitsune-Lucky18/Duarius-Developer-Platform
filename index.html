Features

Analytics

Real-time telemetry for your scripts. Kicks, retention curves, executor breakdown, geography, session length — all live in your dashboard.

  • Live execution tracking
  • Retention & churn analysis
  • Executor & platform mix

Key System

A managed key system with ad-gating, watermarking, and automatic rotation. Lootlabs and Linkvertise wired in. Zero revenue share.

  • Ad-gated key generation
  • Runtime watermarking

Push a version, roll back instantly. Each authorized player gets their own watermarked copy — if it leaks, you know who did it.

  • Version control & rollback
  • Per-player watermarking
  • CDN-powered delivery
  • Rolling updates
